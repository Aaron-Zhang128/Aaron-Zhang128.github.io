# Aaron Zhang — Portfolio

A personal portfolio that plays like a game: boot screen, XP/levels, achievements,
and a playable "Draw a Perfect Circle" mini-game.

**Live:** https://aaron-zhang128.github.io/

- `index.html` / `arcade.css` / `arcade.js` — the arcade site
- `v1.html` / `styles.css` / `script.js` — earlier dark-cinematic version
- `assets/` — game icons

Built from scratch — no frameworks, no build step.
